# BLE 接口与控制协议

## BLE 接口

| 项目 | 内容 |
|---|---|
| 蓝牙名称 | `IG_REMOTE_S3` |
| Service UUID | `6E400001-B5A3-F393-E0A9-E50E24DCCA9E` |
| RX UUID | `6E400002-B5A3-F393-E0A9-E50E24DCCA9E` |
| TX UUID | `6E400003-B5A3-F393-E0A9-E50E24DCCA9E` |
| TX 属性 | Read + Notify |
| RX 属性 | Write + Write Without Response |
| 正常发送周期 | 约 20 ms |

## 数据帧

```text
Byte0   Byte1   Byte2
0xAA    0x01    CMD
```

前两个字节固定为 `AA 01`，第三个字节表示操作命令。

## 命令表

| 操作 | CMD | 完整帧 |
|---|---:|---|
| 主页/中键/SW 短按 | `0x00` | `AA 01 00` |
| 下 | `0x01` | `AA 01 01` |
| 左 | `0x02` | `AA 01 02` |
| 右 | `0x03` | `AA 01 03` |
| 上 | `0x04` | `AA 01 04` |
| 初始/空白/睡眠前 | `0xFF` | `AA 01 FF` |

## 锁存规则

- 上、下、左、右触发后，当前命令被锁存。
- 五向开关松开或摇杆回中后，不自动清除方向命令。
- 遥控器继续每约 20 ms 发送最后一次命令。
- 新方向操作会替换旧命令。
- 短按中键或摇杆 SW 后，切换为主页命令 `AA 01 00`。
- BLE 新连接后，从 `AA 01 FF` 开始发送。

## 深度睡眠规则

1. 中键或摇杆 SW 长按 2 秒。
2. 松开按键。
3. 睡眠前发送 `AA 01 FF`。
4. BLE 关闭，原连接断开。
5. ESP32-C3 进入深度睡眠。
6. 再按 GPIO3 对应的中键或 SW。
7. ESP32-C3 重新启动并恢复 BLE 广播。
8. IG 接收端需要重新连接；能否自动连接取决于 IG 端程序。
